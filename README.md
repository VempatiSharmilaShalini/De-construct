
# De-construct

A Business and Customer Query application built with Python, Streamlit and OpenAI.

## Tech Used
- Python
- Streamlit
- OpenAI API
- Pydantic

## How to Run
1. Download or clone this repository
2. Install the requirements:
   pip install -r requirements.txt
3. Run the app:
   streamlit run app.py
